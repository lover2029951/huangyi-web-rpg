# 🗡️ 黃易群俠傳 Web：時空浪人

Path of Exile 風格的武俠網頁 RPG，純前端單機遊戲。

## 🎮 立即遊玩

### 方式 1：直接開啟（最簡單）

下載整個資料夾後，**雙擊 `index.html`** 即可開始遊戲。

> ⚠️ 建議使用 Chrome 或 Edge 瀏覽器

### 方式 2：本機伺服器（推薦）

```bash
# 有 Python
python -m http.server 3000

# 有 Node.js
npx serve . -l 3000
```

然後開啟 <http://localhost:3000>

### 方式 3：線上遊玩

若已部署到 GitHub Pages / Gitee Pages，直接開啟網址即可。

## ✨ 遊戲特色

### 🗺️ 異界輿圖（Atlas）
- **T1~T16 階級地圖**，每階有專屬石徽圖示
- **地圖通貨改造**：蛻變石、增幅石、改造石、點金石、混沌石、重鑄石
- **輿圖天賦樹**：33 節點、4 大分支（精隨主題）
- **霸主系統**：每階首殺永久 +1 天賦點，25% 掉落高一階地圖
- **復活機制**：每角色獨立 3 次

### ⛏️ 地心礦坑（Delve）
- 無限深度，越深越強
- 獨立戰鬥系統（與一般／輿圖完全隔離）
- 硫磺燃料、化石、珠寶掉落

### ⚔️ 三套獨立戰鬥系統
| 系統 | 適用 | 獨立設定 |
|---|---|---|
| **時空內掛** | 一般戰鬥 | 每角色獨立戰術 |
| **打圖戰術** | 異界輿圖 | 每角色獨立戰術 |
| **礦坑戰術** | 地心礦坑 | 每角色獨立戰術（43 項設定）|

三者**互斥**，同時只能進行一種。

### 🌳 十五大門派
峨嵋、少林、武當、魔門、陰癸、慈航、淨念禪院…各有專屬武學與特色。

### 💎 PoE 裝備工藝
- 十大部位裝備
- 白／藍／黃／暗金傳奇稀有度
- 詞綴系統、通貨工藝
- 精隨禁錮（3% 怪物生成，擊殺必掉）

### 🏰 其他系統
- 金司馬區（建築、工人、船運、符文、重組）
- 幫會系統（八大建築排班、祝福、後天改命）
- 小鎮經營、彩券、好友、拍賣場

## 🔧 技術說明

- **純前端**：無後端依賴，所有資料存於 `localStorage`
- **單一 HTML**：`game.html` 已將 162 個 JS 檔全部內聯，避免防毒誤報
- **零外部依賴**：不載入任何 CDN 的 JS/CSS

### 為什麼用單一 HTML？

原本的專案有 314 個獨立 `.js` 檔，打包成壓縮檔後常被防毒誤報為 `Trojan:Script/...`（啟發式偵測誤判）。

改成單一 `game.html` 後：
- 防毒幾乎不會誤報
- 傳輸更方便（少一個資料夾）
